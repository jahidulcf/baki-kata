# বাকি খাতা - Digital Shop Credit Ledger

একটি সুন্দর ডিজিটাল বাকি খাতা যা ছোট দোকানদের জন্য ক্রেডিট বিক্রয় এবং পেমেন্ট ট্র্যাক করতে সাহায্য করে।

## বৈশিষ্ট্য

✅ **সম্পূর্ণ অফলাইন** - ইন্টারনেট ছাড়াই কাজ করে  
✅ **স্থানীয় সংরক্ষণ** - সব ডাটা আপনার ডিভাইসে থাকে  
✅ **মোবাইল-প্রথম** - ছোট ডিভাইসের জন্য অপ্টিমাইজড  
✅ **সহজ ব্যবহার** - কোন জটিল মেনু নেই  
✅ **বাঙালি ভাষা** - সম্পূর্ণ বাংলা ইন্টারফেস  
✅ **PWA সমর্থন** - ডেস্কটপ/স্মার্টফোনে ইনস্টল করুন  
✅ **PDF রিপোর্ট** - গ্রাহক রিপোর্ট তৈরি করুন

## মূল বৈশিষ্ট্য

### ড্যাশবোর্ড
- মোট পাওনা পরিমাণ
- এই মাসে আদায় করা অর্থ
- মোট গ্রাহক সংখ্যা
- সাম্প্রতিক লেনদেনের তালিকা

### গ্রাহক ব্যবস্থাপনা
- গ্রাহক যোগ করুন/সম্পাদনা করুন/মুছুন
- গ্রাহক অনুসন্ধান (নাম বা ফোন দ্বারা)
- গ্রাহককে কল করুন
- পাওনার ইতিহাস দেখুন

### লেনদেন
- ক্রেডিট বিক্রয় যোগ করুন (পাওনা বৃদ্ধি)
- পেমেন্ট রেকর্ড করুন (পাওনা হ্রাস)
- লেনদেন ইতিহাস দেখুন
- তারিখ এবং নোট যোগ করুন

### ডেটা ব্যাকআপ
- ডেটা এক্সপোর্ট করুন (JSON ফর্ম্যাটে)
- ডেটা ইম্পোর্ট করুন
- সম্পূর্ণ ডেটা মুছুন

## প্রযুক্তিগত স্ট্যাক

- **HTML5** - শব্দার্থিক মার্কআপ
- **Tailwind CSS** - ইউটিলিটি-ফার্স্ট CSS ফ্রেমওয়ার্ক
- **JavaScript (Vanilla)** - কোন ফ্রেমওয়ার্ক নেই
- **LocalStorage** - ডেটা সংরক্ষণ
- **Service Worker** - অফলাইন সমর্থন
- **PWA** - মোবাইল-নেটিভ অভিজ্ঞতার জন্য

## ব্যবহার

### নতুন গ্রাহক যোগ করুন
1. "গ্রাহক" ট্যাবে যান
2. "+ নতুন গ্রাহক" বোতাম ক্লিক করুন
3. নাম, ফোন (ঐচ্ছিক), ঠিকানা (ঐচ্ছিক) প্রবেশ করুন

### লেনদেন যোগ করুন
1. গ্রাহক তালিকা থেকে গ্রাহক নির্বাচন করুন
2. "+ নতুন হিসাব" ক্লিক করুন
3. লেনদেনের ধরন নির্বাচন করুন
4. পরিমাণ এবং তারিখ প্রবেশ করুন
